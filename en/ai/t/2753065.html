Removing

Refitting

For versions with manually-operared exterior rear view mirrors.

1. Remove rubber from the exterior rear view mirror adjustment lever.

2. Undo the ring nut.

3. Using a suitable tool, remove the corner trim.

Applies to: all engines; all production periods

For versions with electrically-operated exterior rear view mirrors.

1. Using a suitable tool remove the corner trim.

Applies to: all engines; all production periods

Refitting

Removing

For versions with manually-operated exterior rear view mirrors.

Fit the corner trim and check that it is secure.

Tighten the ring nut.

Fit the rubber on the exterior rear view mirror adjustment lever.

For versions with electrically-operated exterior rear view mirrors.

Fit the corner trim and check that it is secure.
