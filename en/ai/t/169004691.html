Applies to: all engines; all production periods; only with equipment: Right hand drive

Description

The front and rear door lock motors are operated simultaneously by using:

  • the ignition key;
  • the switch (knob) for the front driver's door;
  • the remote control.

Lock operation: using the ignition key in the driver's front door, or using the remote control, with all the doors perfectly shut, they can be locked simultaneously.

Lock release operation: using the ignition key in the driver's front door, or using the remote control, all the doors can be unlocked.

This control logic is controlled by the body computer node
