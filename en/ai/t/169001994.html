Applies to: all engines; all production periods; only with equipment: Manual Air Conditioning

The fan does not work when the speed control selector is used.

Applies to: all engines; all production periods; only with equipment: Manual Air Conditioning

Results of the tests

1

SPEED SELECTOR CHECK

All OK

Problems encountered

Operation

Check that the fan is working at the maximum speed: if it only works at the maximum speed, the resistor should be replaced. Check whether the resistor thermal fuse is broken by measuring the electrical continuity at the thermal fuse securing points.

Move on to Step 2

Failed operation of speed selector

Replace the ceramic resistor

2

CHECK ON CORRECT OPERATION OF FAN

All OK

Problems encountered

Operation

Check for loose connections in the electrical wiring. Disconnect/reconnect the connection to the engine support. Check that it rotates at all speeds by activating them using the switch. If it does not rotate at the maximum speed, check the vehicle fuse. If the defect persists, before replacing it, provide a direct battery supply and check that it rotates at maximum speed.

End of diagnosis

Electrical connections loose

Renew the electrical connections

Fan not working

Replace the fan

Op. 5040C30 FAN MOTOR - R+R

Applies to: all engines; all production periods; only with equipment: Automatic Air Conditioning

The fan does not work when the speed control selector is used.

Applies to: all engines; all production periods; only with equipment: Automatic Air Conditioning

Results of the tests

1

CHECK ON OPERATION OF FAN BY CLIMATE CONTROL SYSTEM CONTROL UNIT

All OK

Problems encountered

Operation

With the engine started, set the climate control system control unit in the AUTO position, adjust the temperature to 22 °C, position the recirculation to outside air intake and the distribution to the front position. Adjust the fan button (+ side) gradually increasing the speed set and then decreasing the speed using the (- side) button and check the effect on the variation of the air flow rate

End of diagnosis

The fan does not work

Move on to Step 2

2

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the diagnostic equipment and check:

  • that there are no errors at the passenger compartment fan
  • that there are no errors linked to the fan (short circuit errors)

End of diagnosis

Error at the passenger compartment fan.

Move on to Step 3

Short circuit error

Move on to Step 3

3

CHECK ON CORRECT OPERATION OF FAN

All OK

Problems encountered

Operation

Check whether the electrical wiring connections are loose: disconnect/reconnect the connection to the engine mounting.

Repeat the checks using the Examiner and check whether the fan error reoccurs. Carry out the tests described in Test 5040CE in order

See Test 5040C AIR CONDITIONER BOX AND COMPONENTS

End of diagnosis

Malfunction of the regulator built into the fan motor support

Replace the fan motor support
