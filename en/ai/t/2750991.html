B10 ENGINE DOES NOT START / UNDER NO CIRCUMSTANCES

Applies to: engines: 1.1, 1.2 8v; all production periods

The engine does not start. When the key is turned, the instruments light up, the starter motor turns to the AVV position, but the engine will not start.

The MIL warning light should come on with the ignition on and go out once the engine has started. If the Code is faulty, the CODE system failure will be indicated by the instrument panel.

Applies to: engines: 1.1, 1.2 8v; all production periods

PRELIMINARY CHECKS

All OK

Problems met

Operation

Turn the ignition on and check that the CODE is working properly

The I.E light should come on for about 4 seconds and then switch off, while the CODE light should come on for about 1 second and then switch off.

Then check:

  • that the inertia switch has not been operated;
  • that there is fuel in the tank
  • that the air filter and air intake circuit are working properly
  • correct operation of the exhaust pipes;
  • that there are no leaks from the high- and low-pressure fuel pipes;
  • that there is no petrol, water, paraffin or dirt in the diesel filter

Continue to Step 1

Continue according to the instructions
