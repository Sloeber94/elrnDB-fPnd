Applies to: all engines; all production periods

The diagnostic equipment signals the following error: "U1601 - CAN error"

Applies to: all engines; all production periods

This error is signalled if there is an open circuit (power supply or earth) in the CAN lines

Applies to: all engines; all production periods

1

CAN CHECK

All OK

Problems encountered

Operation

Check the CAN network impedence is correct

See Test 5505OA CAN LINE C CHECK

Move on to Step 3 1

  • ABS control unit side resistance non compliant
  • CAN electrical connections faulty
  • Replace ABS control unitOp. 3340A20 ABS ELECTRONIC CONTROL UNIT - R+R
  • Restore correct connection and move on to Step 3

3

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Clear the errors using the Examiner

Carry out a road test

See Test 3340OA A.B.S. SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis

The fault persists

Move on to Step 1
