The diagnostic equipment signals the following error: "C1800 - Supply voltage"

Applies to: all engines; all production periods

This error is signalled if the control unit detects a battery voltage that is too high or too low

Applies to: all engines; all production periods

1

POWER SUPPLY CIRCUIT CHECK

All OK

Problems encountered

Operation

Check that the supply voltage at the battery terminals is correct.

Check the power supply wiring from the battery to the ABS control unit

See E7020 ABS

there should be no drop in voltage between the battery and the control unit

Move on to Step 2 1

  • Battery voltage not correct
  • Drop in voltage in the wiring
  • Recharge the battery, if necessary, replace itOp. 5530B10 BATTERY - R+R
  • Renew the wiring, if necessary, replace the faulty components

2

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Delete the errors using the diagnostic equipment.

Carry out a road test

See Test 3340OA A.B.S. SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment.

End of diagnosis
