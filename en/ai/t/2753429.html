2127I What to do for error in Selespeed control unit

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

No accelerator pedal information

The signal is received by the Selespeed control unit via the CAN line.

Select the CAN information on the Examiner Plus or Smart and check for the presence of any faulty control units.

Check the state of the connections and the continuity of the wiring for the line, in particular between the faulty control units.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Clutch solenoid current

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Selespeed pump

Check pump fuse and relay status

Check the state of the connections and the continuity of the wiring.

Check pump winding insulation and continuity.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Drainage oil accumulator error

Replace the accumulator.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Lever switch error (any of the four buttons or the Eco/Normal button):

Lever check

Connect the Examiner diagnostic equipment and select the 'LEVER STATUS' display.

Make all the selections possible using the buttons on the steering wheel (one at a time) checking that the change in state on the Examiner Plus or Smart is correct; the list of selections to be made is as follows:

  • Lever up (+) (forwards)
  • Lever down (-) (backwards)
  • Lever in neutral (N)
  • Lever in reverse (R)
  • Lever released

Check on ECO button

Select the input state display (ON/OFF) for the ECO button.

Press and release the Economy operation selector button located at the base of the gear lever and at the same time check on the Examiner that there has been a momentary change of state.

Select AUTO mode via the lever and at the same time check on the Examiner Plus or Smart that there has been a momentary change of state.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Control unit earth error

Check the state of the tightening of the earths to the bodyshell and the engine.

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Microprocessor 2 error

Replace the Robotised Gearbox control unit 2127E10 hydraulic speed selection system control unit - r r

Load relay error

Check the state of the battery in accordance with the specific procedure.

Check the state of the connections and the continuity of the wiring. In particular check the chain of elements providing the supply for the control unit (wiring, fuses, relays, etc.).

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Pump relay error

Check the state of the connections and the continuity of the wiring. In particular, check the chain of elements providing the supply to the pump (fuses, relays, etc.).

There are cases where the fastom connectors housed in the relay holder base are detached.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

CAN network errors

Check:

  • that the network monitors all the control units (warning: any control unit connected to the CAN could cause network operating problems).
  • the state of the connections and the continuity of the wiring involving the CAN line. It is a good idea not to be restricted to a visual inspection of the connection but to carry out a test subjecting it to mechanical stress (pull the wires, twist them, check the stability of the pins, etc.).

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Electromagnetic brake (Selection solenoid)

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Odd or even gear engagement (engagement solenoids)

Carry out active diagnosis of solenoid valve. If the test is not successful, move on to the next step

Check the state of the connections and the continuity of the wiring.

Carry out the active diagnosis of the solenoid valve again.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Brake switch

The signal is received from the Selespeed control unit either via the wire or via the CAN line.

Check the state of the brake switch:

Turn the ignition key to the ON position.

Connect the Examiner diagnostic equipment and select the display of the input state (ON/OFF) for the switch on the brake pedal.

Press the brake pedal and check that the value displayed changes.

If there is no change of state, check the switch on the brake pedal, its fastening, its positioning, the state of the connections and the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Clutch sensor

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Engagement sensor (engine off)

If this error is present, the gear change and cranking are disabled.

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Engagement sensor (engine on)

If this error is present, the gear change is slower than usual because the system operates in recovery mode.

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Selector sensor

If this error is present, the gear change is slower than usual because the system operates in recovery mode.

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Clutch plate speed (this signal is detected by the sensor which reads the speed of the main shaft)

Check the state of the connections and the continuity of the wiring.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Engine speed (from wire)

Check connection between engine management control unit and the Robotised Gearbox unit is correct because this signal is sent by the engine management control unit via a dedicated wire.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Vehicle speed

The signal is received by the Robotised Gearbox control unit via the wire and replicated on the CAN line.

Check the state of the connections and the continuity of the wiring.
