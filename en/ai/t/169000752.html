The diagnostic equipment signals the following error: "U1700 - Body computer node missing"

Applies to: all engines; all production periods; only with equipment: Smart gearbox

The diagnostic equipment signals the following error: "U1700 - Body computer node missing"

Applies to: all engines; all production periods

This error is signalled if the control unit does not detect the body computer

Applies to: all engines; all production periods; only with equipment: Smart gearbox

This error is signalled if the control unit does not detect the body computer

CAN CONTROL UNITS FAULT DIAGNOSIS

All OK

Problems encountered

Operation

Carry out a fault diagnosis using the Examiner on the CAN control units to check for the presence of errors at the NBC - NPL

Move on to Step 2 1

  • Presence of errors at CAN control units
  • Errors present in the Body Computer
  • Resolve the problem for the control unit where the error is present and continue to step 2
  • Resolve the problem for the body computer and continue to step 2

4

CHECK USING THE EXAMINER

All OK

Problems encountered

Operation

Check that error U1701 (NCM missing) and that error U1717 (NGE missing) are not also present in the ABS control unit with the counter equal to or close to the reading for U1700 (NBC missing)

Move on to Step 5 1

Error U1717 present in the ABS control unit

Proceed as instructed for error U1717

5

ELECTRICAL CHECKS

All OK

Problems encountered

Operation

Check the continuity of the wiring for the CAN between the NGE and NBC

Move on to Step 6 1

Wiring faulty

Restore the correct connection between the NGE and NPL NBC Move on to Step 6

6

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Delete the errors using the diagnostic equipment.

Carry out a road test

See Test 3350EA ESP SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis
