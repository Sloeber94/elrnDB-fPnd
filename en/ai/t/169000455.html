The diagnostic equipment signals the following error: "C1103 - EOL configuration not programmed in the Body Computer"

Applies to: all engines; all production periods

this error is signalled if the Body Computer has received an invalid vehicle configuration

Applies to: all engines; all production periods

1

CONTROL UNIT COMPATIBILITY CHECK

All OK

Problems encountered

Operation

Check that the control unit design number is compatible with the part number for the Model-Version-Series in question

Move on to Step 2

The design number is not compatible

Move on to Step 3

2

RECALL CAMPAIGNS CHECK

All OK

Problems encountered

Operation

Check that there is not a recall campaign in progress which involves changing the ABS control unit

Move on to Step 3

There are recall campaigns in progress

Replace the ABS electrohydraulic control unit with the new one, compatible with the recall campaign

Op. 3340A12 ABS HYDRAULIC AND ELECTRONIC CONTROL UNIT - R.R.

3

BODY COMPUTER REPLACEMENT

All OK

Problems encountered

Operation

Replace the Body Computer

Op. 5505A32 BODY COMPUTER - R.R

Enter into the fault diagnosis using the Examiner and delete the errors in the ABS control unit

End of diagnosis
