Applies to: all engines; all production periods

Description

The front and rear door lock motors are activated simultaneously through the use of:

  • the ignition key;
  • the driver's front door switch (knob);
  • the remote control.

Locking operation: using the ignition key in the driver's front door, or using the remote control, when the doors are firmly shut, all the doors are locked simultaneously.

Unlocking operation: using the ignition key in the driver's front door, or using the remote control, all the doors are unlocked.

This operating logic is controlled by the body computer node.
