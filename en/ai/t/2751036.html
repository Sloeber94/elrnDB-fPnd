Applies to: all engines; all production periods

When the ASR is switched on the 'ASR on' message is not shown on the display for 5 seconds; the LED in the button remains on (indicating that it is switched off).

Applies to: all engines; all production periods

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner diagnostic equipment to the diagnostic connector and check the following at the brake nodes:

  • for faults in error mode;
  • for plausibility of all parameters in parameter mode;

Continue to Step 2

An error is detected in the control unit

Continue following the instructions for the diagnostic equipment

2

SWITCH CHECK

All OK

Problems met

Operation

Check the operation of the ASR switch checking that there is a short circuit with the button pressed and an open circuit with the button released See E7021 ASR / TCS

Continue to Step 3

Faulty switch

Replace switch Op. 3350A10

3

CHECKING ELECTRICAL EQUIPMENT

All OK

Problems met

Operation

Check the continuity/insulation of the ASR switch connections See E7021 ASR / TCS

Continue to Step 4

No continuity/insulation

Restore the correct connections See E7021 ASR / TCS

4

Continue as instructed by the tester

All OK
