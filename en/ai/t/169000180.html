Applies to: all engines; all production periods

The navigation system detects an incorrect position: junctions detected sooner or later

Applies to: all engines; all production periods

The navigation system takes about 100km to self-regulate accurately from the first system start-up and when the tyres are changed for others of a different size. Under conditions or poor wheel grip (skidding on ice), the system temporarily detects an incorrect position

Applies to: all engines; all production periods

1

CHECK THE MAP CD

All OK

Problems encountered

Operation

Check that the map CD is clean

Check that the map CD is not scratched

Check that the CD is compatible with the type of navigation system

Check that the defect does not arise immediately after replacing the tyres

Move on to Step 2

  • Map CD dirty
  • Map CD scratched
  • CD does not correspond
  • The defect occurred after replacing the tyres and is therefore due to an imprecise wheel rpm distance conversion factor
  • Clean the map CD using a clean cloth
  • Replace the map CD
  • Replace with a specific map CD
  • Cover about 100 km under excellent satellite reception conditions in order to reset the conversion factor
