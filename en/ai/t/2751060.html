Applies to: all engines; all production periods

When operated with the dipped beam headlamps on, the headlamp adjustment knob does not work If the dipped beam headlamps do not work either, first see I05 DIPPED HEADLAMPS NOT WORKING

Applies to: all engines; all production periods

Results of the tests

1

CHECK ON HEADLAMP ALIGNMENT CORRECTOR ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check:

  • connection between left control panel and NQS;
  • left control panel earth;
  • connection between dashboard control unit and headlamp alignment motors;
  • connection between dashboard control unit and instrument panel;
  • headlamp alignment motor and headlamp alignment control earth See E3080 HEADLAMP AGLINMENT CORRECTOR

Continue to Step 2

Connections not correct

Restore the connections See E3080 HEADLAMP AGLINMENT CORRECTOR

Connections not correct

Restore the earth contacts See E3080 HEADLAMP AGLINMENT CORRECTOR

2

CHECK ON HEADLAMP ALIGNMENT CONTROL

All OK

Problems met

Operation

Check the operation of the headlamp alignment control device See E3080 HEADLAMP AGLINMENT CORRECTOR

Continue to Step 3

Headlamp alignment control device faulty

Replace instrument panel Op. 5560B11

Instrument panel faulty

Replace instrument panel Op. 5560B11

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
