7050C11 Single CUSHION of sliding rear seat - S.R.

1. Disconnect the seat sliding control cables from the guide release devices.

2. Release the sliding control cables from the bands on the cushion frame.

3. Disconnect the luggage compartment sliding control cable, releasing it from the cushion frame.

4. Undo the bolts fixing the backrest folding control cables return springs to sliding control device.

5. Undo the bolts fixing the seat sliding control device to the cushion frame.

6. Remove the seat sliding control device, complete with control cables.

Applies to: all engines; all production periods

Refitting

Removing

Fit the seat sliding control device, complete with control cables.

Tighten the bolts fixing the seat sliding control device to the cushion frame.

Tighten the bolts fixing the backrest folding control cable return springs to the sliding control device.

Connect the luggage compartment sliding control cable to the cushion frame.

Connect the seat sliding control cables to the guide release devices.

Secure the seat sliding control cables to the bands on the cushion frame.

Check the operation of the release device on the guides, using the luggage compartment sliding control cable.
