I06 MAIN BEAM HEADLAMPS NOT WORKING

Applies to: all engines; all production periods

With the dipped headlamps switched on (stable position) or in the flashing mode, when the stalk unit ring nut is operated, the main beam headlamps do not work

Applies to: all engines; all production periods

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic socket

check

  • that there are no faults in the Body Computer
  • the operation of the lights in active diagnosis.

Continue to Step 3

Body Computer faulty

Continue according to the instructions for the diagnostic equipment

Body Computer faulty

Continue to Step 2

2

CHECK ON INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 3

Bulbs damaged

Replace bulbs Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

Front right light cluster faulty

Repair or replace front lights cluster Op. 5540B08

Front left light cluster faulty

Repair or replace front lights cluster Op. 5540B07

3

MAIN BEAM HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • left and right main beam headlamp fuses
  • main beam headlamps relay feed;
  • connection between steering column switch unit and Body Computer;
  • connection between Body Computer and engine compartment control unit;
  • connections between engine bay control unit and bulbs;
  • bulb earth See E2012 MAIN BEAM HEADLAMPS

Continue to Step 4

Blown fuses

Replace the fuses, then search for the cause of the problem

Blown fuses

Restore the connections See E2012 MAIN BEAM HEADLAMPS

Blown fuses

Restore the earth to the bulbs See E2012 MAIN BEAM HEADLAMPS

4

CHECK ON STEERING COLUMN SWITCH UNIT

All OK

Problems met

Operation

Check that the stalk unit is working properly See E2012 MAIN BEAM HEADLAMPS

Continue to Step 5

Stalk unit faulty

Replace the stalk unit Op. 5550A12

5

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is supplied properly

Check that when an earth signal from stalk unit to Body is activated, an earth signal is emitted from the Body to drive the dipped beam headlamps relay

Continue to Step 6

Incorrect supply

Restore the supply See E2012 MAIN BEAM HEADLAMPS

Incorrect supply

Replace the Body Computer Op. 5505A32 body computer - r r

6

Continue as instructed by the tester

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
