C16 THE GEARS DO NOT ENGAGE IN "AUTO" OPERATION

Applies to: engines: 1.2 8v; all production periods

Sometimes, for a few seconds no gear can be engaged from the lever

Failed engagement of reverse gear and/or neutral

It is not possible to request a gear change using the lever (gear suggestion, obviously for the request to be accepted all the engine conditions in order to make the gear change must be satisfied)

Applies to: engines: 1.2 8v; all production periods
