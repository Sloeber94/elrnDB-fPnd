Applies to: all engines; all production periods

Functional description

Via the aerial for the Fiat-CODE system P091, the body computer node M001 receives, at pins 10 and 19 of connector H, the code of the inserted key, and checks that it is valid by comparing it with those in its memory.

Applies to: engines: 1.1, 1.2 8v; all production periods

Functional description

If the code is correct, the body computer node M001, via the CAN network, enables at pins 20 and 29 of connector B the control unit M010 to start the engine when required and, still via the B CAN network, controls the switching on of the warning lights on the instrument panel E050.

Applies to: engines: 1.2 8v; all production periods

Functional description

If the code is correct, the body computer node M001, via the C CAN network, enables at pins 36 and 52 of connector B the control unit M010 to start the engine when required and, still via the B-CAN network, controls the switching on of the warning lights on the instrument panel E050. The engine management control unit M010 (pin 11 connector B) and the body computer node M001 (pin 13 connector D) are connected via specific serial line 'W'; this line has a CODE system recovery function if there are problems in the C-CAN line.

Applies to: engines: 1.3 JTD 16v; all production periods

Functional description

If the code is correct, the body computer node M001, via the B-CAN , enables at pins 58 and 59 of connector B the control unit M010 to start the engine when required and, still via the B-CAN, controls the switching on of the warning lights on the instrument panel E050. The engine management control unit M010 (pin 66 connector B) and the body computer node M001 (pin 13 connector D) are connected via specific serial line 'W'; this line has a CODE system recovery function if there are problems in the B-CAN line.

Applies to: all engines; all production periods

Functional description

The system is only activated if the ignition is on; the signal reaches the body computer node at pin 1, connector L (for further details See E1010 SUPPLY ).
