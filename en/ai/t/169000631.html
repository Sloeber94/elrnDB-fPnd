Applies to: all engines; all production periods

The diagnostic equipment signals the following error: "C1107 Communication with failure warning lights"

Applies to: all engines; all production periods

This error is signalled if there is an error in the B-CAN between the Body Computer and the instrument panel or if one of the warning lights (EBD, ABS, ASR or ESP) is faulty

Applies to: all engines; all production periods

1

PANEL INITIAL CHECK

All OK

Problems encountered

Operation

Turn the key ON and check that the instrument panel carries out the initial check on the warning lights

Move on to Step 2 1

One or more of the warning lights do not come on

  • Replace the instrument panelOp. 5560B10 ANALOGUE CONTROL PANEL - R+R
  • Move on to Step 4

3

ELECTRICAL CONNECTIONS CHECK

All OK

Problems encountered

Operation

Check that the instrument panel is correctly connected to the CAN network

See E4010 INSTRUMENT PANEL

Move on to Step 4 1

Electrical connections faulty

Restore the correct connections, if necessary, replace the instrument panel.

Op. 5560B10 ANALOGUE CONTROL PANEL - R+R

Move on to Step 4

4

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Clear the errors using the Examiner

Carry out a road test

See Test 3340OA A.B.S. SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis
