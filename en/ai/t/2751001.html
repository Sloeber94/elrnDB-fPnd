CONTROL UNIT ERRORS CHECK

All OK

Problems met

Operation

Check that there are no control unit errors. In particular:

  • Clutch sensor error
  • Lever switch error (any one of the 4 switches or the ECO/Normal switch)
  • Microprocessor 2 error
  • Even gear engagement error
  • Odd gear engagement error
  • Clutch solenoid current error
  • Electromagnetic brake error (Selection solenoid)
  • Control unit earth error
  • Load relay error

Continue to Step 5

Presence of one or more of the errors included in the list

Continue to Step 1

Problems met

Operation

Continue to Step 3

Faulty connections (Clutch sensor, Odd or even gear engagement, Clutch solenoid current error, Electromagnetic brake error, Control unit earth error and/or Load relay error)

Repair/replace the wiring

Continue to Step 3

The state displayed is not correct (Lever switch error - Lever check)

Check the connections, continuity of the wiring and the gear lever

Continue to Step 3

There is no change of state and/or the word 'ECO' is not displayed (Lever switch error - Check ECO button)

Check the button and wiring
