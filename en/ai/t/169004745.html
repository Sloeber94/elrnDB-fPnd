Applies to: all engines; all production periods; only with equipment: Right hand drive

Description

The electric windows for the front doors are operated using the special switches in the dashboard.

They can be operated either manually or automatically, in accordance with the following logic:

  • manual operation is by pressing the control switch for between 50ms and 300ms;
  • automatic operation is by pressing the control switch for longer than 300ms.

The operation of the electric window is interrupted in the following cases:

  • when automatic movement is in progress and the control switch is pressed again (closing or opening);
  • in the (upper or lower) end of travel position, for both automatic and manual movement.

When the ignition is turned OFF, the electric window function is activated for about 2 minutes in manual mode only. When one of the two doors is opened, this function is inhibited.
