The diagnostic equipment signals the following error: "C1435 - Longitudinal acceleration sensor not calibrated"

Applies to: all engines; all production periods

This error is signalled if the acceleration sensor has not been calibrated

Applies to: all engines; all production periods

1

LONGITUDINAL ACCELERATION SENSOR CALIBRATION

All OK

Problems encountered

Operation

Connect the Examiner, enter diagnostic mode and select the longitudinal acceleration sensor. Calibrate the sensor by following the procedure described.

Move on to Step 2 1

The sensor cannot be calibrated

Replace the sensor

Op. 3350E31 SENSOR FOR LONGITUDINAL ACCELERATION (HILL HOLDER) - R.R .

Move on to Step 2 1

2

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Delete the errors using the diagnostic equipment.

Carry out a road test

See Test 3350EA ESP SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis

The fault persists

Move on to Step 1 1
