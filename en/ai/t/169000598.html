Applies to: all engines; all production periods

The diagnostic equipment signals the following error: "C1417 - Steering Angle Sensor not calibrated"

Applies to: all engines; all production periods

This error is signalled if the calibration of the steering angle sensor has not be carried out. The sensor is incorporated in the electric steering

Applies to: all engines; all production periods

1

RECALIBRATING THE STEERING ANGLE USING A DIAGNOSTIC TESTER

All OK

Problems encountered

Operation

Connect the diagnostic equipment and, in the ACTIVE DIAGNOSIS mode, carry out the STEERING ANGLE CALIBRATION, making sure of a successful outcome.

Move on to Step 2 1

The outcome of the procedure is not positive

Replace the steering angle sensor

Op. 3350E20 STEERING ANGLE SENSOR R R

2

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Clear the errors using the Examiner

Carry out a road test

See Test 3350EB STEERING ANGLE SENSOR OPERATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis
