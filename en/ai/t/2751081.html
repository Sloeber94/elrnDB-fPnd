Applies to: all engines; all production periods

With the ignition key in the ON position, the fuel gauge indicator is not working properly or it indicates a different level from what is actually in the tank.

the fuel level message is supplied by the Body Computer Node and is made available to the Instrument Panel Node via the B-CAN; (the Body Computer Node also sends the fuel level sensor error message).

Applies to: all engines; all production periods
