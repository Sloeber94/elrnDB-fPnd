Applies to: engines: 1.2 8v, 1.3 JTD 16v; all production periods; only with equipment: Smart gearbox

Operational description

The electronic control units that communicate via the CAN (B CAN and C CAN) exchange information by means of the body computer node M001.

The body computer node receives a direct battery supply at pin 1 connector A and an ignition-operated supply at pin 1 connector L.

The body computer node M001 assumes the role of "information collector" for the information coming from the various nodes, thereby allowing the exchange of data between the B CAN and C CAN.

Connection via B CAN

From connector O, the body computer node receives/sends signals coming:

  • from the radio receiver node M094, pin 1, 3 connector A;
  • from the climate control system control unit M070, pin 9, 10 connector B.

From connector I, the body computer node receives/sends signals coming:

  • from the instrument panel E050, pin 8, 9 connector A.

From connector H, the body computer node receives/sends signals

  • to the diagnostic socket R010, pin 6, 14.

Connection via C CAN

Operational description

The nodes which communicate with one another via the C CAN are:

  • body computer node M001, from pin 11, 12 connector D;
  • from the electric steering control unit M086, pin 2, 3, 7, 8 of connector B;
  • brake system control unit M051 , from pins 45, 25, 35, 14.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Operational description

The nodes which communicate with one another via the C CAN are:

  • the engine management control unit M010, from pin 52, 36 connector B;
  • "selespeed" transmission control unit M054 , from pins 19, 7, 45, 33 connector A;

Applies to: engines: 1.3 JTD 16v; all production periods; only with equipment: Smart gearbox

The nodes which communicate with one another via the C CAN are:

  • the engine management control unit M010, from pin 64, 40 connector B;

Applies to: engines: 1.2 8v, 1.3 JTD 16v; all production periods; only with equipment: Smart gearbox

Operational description

Communication between the various nodes on the C CAN-L line is managed by the short-circuiting junction D097 connector G, while on the node on the C CAN-H line is managed by junction D097 connector H.

The two junctions connect the various nodes in cascade manner, i.e. the same information is transmitted to all the nodes connected to the same junction.

For vehicles with an ELD system, brake system control unit M051 communicates via the C-CAN network with body computer M001 from pins 25 and 45, and with engine control unit M010 from pins 14 and 35.
