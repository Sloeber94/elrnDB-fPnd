Z94 ELECTRIC DRIVE NODE ERROR

Applies to: all engines; all production periods

The diagnostic equipment signals the following error: "U1717 - Electric steering node missing"

Applies to: all engines; all production periods

This error is signalled if the brake control unit does not detect the electric steering (DELPHI electric steering)

Applies to: all engines; all production periods

1

CHECK THE CAN NETWORK USING AN EXAMINER

All OK

Problems encountered

Operation

Check for errors in the network control units

Move on to Step 2

  • Presence of errors in CAN control units
  • Errors present in the electric steering
  • Solve the problem for the control unit where the error is present. Move on to Step 2
  • Solve the problem for the electric steering Move on to Step 2

2

CAN IMPEDANCE CHECK

All OK

Problems encountered

Operation

Check the CAN network impedence is correct

See Test 5505OA CAN LINE C CHECK

Move on to Step 5

  • ABS control unit faulty through impedance that does not conform
  • ABS control unit faulty due to non-compliant impedence
  • Replace ABS control unitOp. 3340A12 ABS HYDRAULIC AND ELECTRONIC CONTROL UNIT
  • Restore CAN

3

CHECK ELECTRIC STEERING POWER SUPPLY

All OK

Problems encountered

Operation

Check the electric steering power supply

Move on to Step 4

Electric steering power supply missing

Restore the power supply and move on to Step 5

4

ELECTRICAL CONNECTION CHECK

All OK

Problems encountered

Operation

Check the wiring from the electric steering to the braking node

Move on to Step 5

Fault in the wiring

Restore the correct connection between the brake control unit and the electric steering

5

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Delete the errors using the diagnostic equipment.

Carry out a road test

See Test 3350EA ESP SYSTEM ACTUATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis
