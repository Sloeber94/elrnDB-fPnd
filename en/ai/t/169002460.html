Applies to: engines: 1.3 JTD 16v; all production periods

Description

The management of the ESP function is entrusted to the braking system control unit which, by processing the values acquired from the various sensors (lateral acceleration sensor, slewing sensor, steering angle sensor, wheel rpm sensors and pressure sensors) using software algorithms, monitors the dynamic control parameters (slipping of the wheels, axle drift, geometry angle) and interprets any errors made by the driver implementing suitable measures to restore the vehicle to a stable condition.

In addition to the sensors mentioned above and obviously the control unit, the system interfaces:

  • on the high speed CAN line (
  • See E1050 CAN CONNECTION LINES
  • with the power unit (brake pump);
  • with the electronic throttle;
  • with the control panel (active type warning lights);
  • with the steering wheel/steering column (steering sensor installation);
  • with the centre floor/passenger compartment (slewing sensor and lateral acceleration sensor installation);
  • engine compartment layout (specific ABS installation).
