M03 ONE OF THE ELECTRIC FRONT WINDOWS IS NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position one of the electric front windows does not wor under any circumstance when the relevant button is operated.

each of the front windows is controlled by a specific door node; the driver's door node in particular can also control the movement of the front passenger window via the B-CAN.

Applies to: all engines; all production periods

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) and check CAN network information for

  • for inactive control units;
  • control unit errors;
  • absence of control unit with error in CAN line

Continue to Step 4

Presence of faults

Continue following the instructions for the diagnostic equipment

Driver's/passenger door node not activated

Continue to Step 2

2

ELECTRICAL EQUIPMENT CHECK (NODE POWER SUPPLY)

All OK

Problems met

Operation

Check the condition of the connection between the boot control unit and the door node concerned

Continue to Step 3

Connections broken

Restore the connections See E3050 ELECTRIC FRONT WINDOWS

3

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner Plus or Smart) to the diagnostic socket and check:

  • that there are no errors in the Door Node involved
  • the operation of the electric window involved through active diagnosis

End of diagnosis

Presence of errors in the Door Node control unit involved

Continue according to the instructions for the diagnostic equipment

Electric window is not activated

Continue to Step 4

4

ELECTRICAL EQUIPMENT CHECK (ELECTRIC WINDOW MOTOR POWER SUPPLY)

All OK

Problems met

Operation

check

  • The condition of the specific fuse in the dashboard control unit
  • the condition of the connection between the services discharge relay in the dashboard control unit and the door node involved
  • the condition of the connection between the door node involved and the electric window motor See E3050 ELECTRIC FRONT WINDOWS

Continue to Step 5

Fuse damaged

Replace fuse

Connections broken

Restore the connections See E3050 ELECTRIC FRONT WINDOWS

5

CHECK ELECTRIC WINDOW DEVICE

All OK

Problems met

Operation

Check the mechanics and any impediments in the electric window device.

Continue to Step 6

Electric window device faulty

Replace the electric window device Op. 7005M21

Impediments are found

Remove the obstacle and check correct operation

6

Continue as instructed by the tester

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
