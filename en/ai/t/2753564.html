Applies to: all engines; all production periods; only with equipment: Smart gearbox

Functional description

The diagnostic connector R010:

  • at pin 16 receives the direct battery supply;
  • at pin 4: earth reference;
  • pin 5: electronic earth;
  • pin 1: data coming from the body computer node M001, referred to the data notifited by the braking system control unit M054.
  • pin 3: data coming from the Air Bag control unit M060;
  • pin 9: data coming from the electric steering control unit M086;
  • pin 7: data coming from the body computer node M001, referred to the data notified by the engine management control unit M010.
  • pin 13: data coming from the body computer node M001, referred to the data notified by the parking control unit M084;

The braking system control unit M051 and the Selespeed gearbox control unit M054 are connected directly to the body computer node M001 which later sends the data acquired to the diagnostic connector R010 via the B-CAN.

The D001 junction is housed, in the interior compartment, at the bottom of the front right pillar, near the door cable pass, passenger side.
