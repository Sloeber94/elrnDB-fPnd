Applies to: engines: 1.1, 1.2 8v; all production periods

The diagnostic equipment signals the following errors: "C1117 - Steering Angle Sensor invalid" and "C1517 - Steering Angle sensor: compensation error"

Applies to: engines: 1.3 JTD 16v; all production periods

The diagnostic equipment signals the following errors: "C1117 - Steering Angle Sensor invalid" and "C1517 - Steering Angle sensor: compensation error"

Applies to: engines: 1.1, 1.2 8v; all production periods

These errors are signalled if there is a short circuit at the CAN (supply or earth), if the sensor is damaged or not correctly fitted.

Applies to: engines: 1.3 JTD 16v; all production periods

CHECKS USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the diagnostic equipment and check the operation of the steering angle sensor.

To do this enter the PARAMETERS ambient and display the STEERING ANGLE parameter: the values should increase when the steering wheel is turned in a clockwise direction (to the right) and decrease when it is turned in the opposite direction

Move on to Step 5

Failed or irregular operation of the steering angle sensor:

Move on to Step 2 1

3

CAN CHECK

All OK

Problems encountered

Operation

Check correct CAN network impedence

See Test 5505OA CAN LINE C CHECK

Move on to Step 5 1

  • Motor control unit resistance non-compliant
  • Body control unit resistance non-compliant
  • Faults in CAN network connections
  • Replace engine control unitOp. 1056B82 INJECTION/IGNITION SYSTEM E.C.U. (ONE) - R + R
  • Replace BodyOp. 5505A32 BODY COMPUTER - R R
  • Restore correct connections and move on to Step 4

4

ELECTRICAL CHECKS

All OK

Problems encountered

Operation

Check the electric steering supply voltage

Check the wiring from the NFR to the NGE

See E7045 ELECTRIC STEERING

Move on to Step 5 1

  • Supply not correct
  • Wiring faulty
  • Restore the correct power supply and replace the faulty components if necessary
  • Renew the wiring and move on to Step 5

5

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Delete the errors using the diagnostic equipment.

Carry out a road test

See Test 3350EB STEERING ANGLE SENSOR OPERATION CHECK

to ensure that the control unit checks whether there are any errors still present.

Return to the workshop and check that the fault is no longer present using the diagnostic equipment

End of diagnosis

The fault persists

Move on to Step 2
