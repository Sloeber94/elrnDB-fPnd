Applies to: all engines; all production periods

A green coloured cable is associated with the C CAN H network whilst a brown coloured cable is associated with the C CAN L network.

- If the "communication error present" is found using the Examiner for the fault diagnosis, check whether the NFR node does not see the NBC (NPL), but does see the NGE and the NCR: the problem is probably to be found in the section between the NCR and the NBC.

- In support of this theory, it is also necessary to check that the NGE sees the NFR and the NCR but not the NBC and that the NCR sees the NGE but not the NBC.
