Applies to: all engines; all production periods

The navigation system on the Connect does not compute a route even if a destination point has been entered

Applies to: all engines; all production periods

1

CHECK THE MAP CD

All OK

Problems encountered

Operation

Check that the map CD is clean and not scratched

Check that the CD is compatible with the type of navigation system

Move on to Step 2 1

  • Dirty and scratched
  • Map CD not compatible with the Connect SW
  • Clean or replace the CD
  • Replace the map CD with a compatible CD

2

CHECK SATELLITE RECEPTION

All OK

Problems encountered

Operation

In NAV mode, check that system indicates reception of at least three satellites

See Test 5580PP GPS ANTENNA MODULE POWER SUPPLY CHECK

Move on to Step 3 1

  • No satellite reception due to defective satellite aerial connection
  • Satellite aerial defective
  • No satellite signal coverage
  • Restore the satellite aerial connection
  • Replace the satellite aerialOp. 5570T61 ANTENNA MULTIFUNZIONI - S.R.
  • Move to an area covered by the satellite signals

3

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Check while on the road that at least three satellites are correctly connected

See Test 5580MC SATELLITE NAVIGATOR OPERATION CHECK

End of diagnosis
