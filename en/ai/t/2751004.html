Applies to: engines: 1.2 8v; all production periods

It skips a gear/the requested gear is not engaged.

If no errors are detected, the problem could be due to incorrect use of the vehicle by the customer.

Applies to: engines: 1.2 8v; all production periods

SENSOR REPLACEMENT

All OK

Problems met

Operation

If there is a gear engagement sensor error and no faults are detected at the connections/wiring, replace it Op. 2127E42 hydraulic selection gearbox shift position sensor - r rand check that the position reading is correct by carrying out a series of C.M.

If there is a gear selector sensor error and no faults are detected at the connections/wiring, replace it Op. 2127E40 hydraulic selection gearbox speed selection position sensor - r rand check that the position reading is correct by carrying out a series of C.M.

It is advisable to mark the two potentiometers in order to be able to recognize them once they have been removed

ROAD TEST

All OK

Problems met

Operation

Carry out a road test, making sure to make as many gear changes as possible with all the available gears (under different engine speed and load conditions).

Check the failed engagement counters in the parameters environment (failed engagement counters in: neutral, 1st-5th and Reverse).

Print out/make a note of the new counter values.

Compare the new values of the parameters with those noted down previously, checking that there is not a signficant increase for one or several counters

End of diagnosis

There is a significant increase for one or more counters

Replace the gearbox Op. 2110A11 manual gearbox with differential - r r for versions with hydraulic selection

9

THE FAULT PERSISTS

All OK

Problems met

Operation

The fault may be caused by false contacts on the gear lever: check the state of the connections and wiring for the lever.

  • At all events, contact Technical Service for further information on the problem.

End of diagnosis
