2127L GEAR LEVER CHECK

Applies to: engines: 1.2 8v; all production periods; only with equipment: Smart gearbox

Turn the ignition key to the ON position.

Connect the Examiner diagnostic equipment and select the 'LEVER STATUS' display.

Make all the selections possible using the gear lever checking that the change in state on the Examiner is correct; the list of selections to be made is as follows:

  • Lever in neutral (N) (stable position)
  • Lever in reverse (R) (stable position)
  • Lever released (stable position)

With the lever in this position (check the state using the Examiner) the following selections can be accessed:

  • Lever in Up position (+) (forwards) (unstable position)
  • Lever in Down position (-) (backwards) (unstable position)

Select the Auto/Manual mode (unstable position).
